How a payment moves

1 · OrderFerry fixes the item and amount on the server when the order is created. Nobody can edit them afterwards.
2 · QuoteThe buyer picks a token. Ferry asks 1Click for an EXACT_OUTPUT quote, which returns a one-time deposit address.
3 · DepositThe buyer sends the quoted amount from any wallet before the deadline. If a payment fails, the funds are refunded to the buyer's refund address.
4 · SettledFerry polls 1Click and marks the order paid only when the reported swap matches this order exactly.

Exact amount, by design

Prices are stored as integer base units, and quotes fix the output amount. Price changes and slippage land on the buyer's side, never in your payout.

Server decides "paid"

A browser callback or a pasted transaction hash can't mark an order paid. Only a matching 1Click status that Ferry checks on the server does.

AI that drafts, never decides

NEAR AI Cloud drafts store copy into a strict schema. You review every field before applying it. The AI can't touch prices, payout addresses or payments.
